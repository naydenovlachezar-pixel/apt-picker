# База данни (Supabase)

Проект: регион Frankfurt (eu-central-1). Миграциите са в `supabase/migrations/`, демо данните се генерират със `node scripts/export-seed.mjs`.

## Таблици

| Таблица | Какво пази |
| --- | --- |
| `organizations` | Клиентите: строители и агенции |
| `org_members` | Кой потребител към коя организация е и с каква роля (`owner`, `editor`, `viewer`) |
| `buildings` | Сградите. `slug` е стойността на `data-building` в кода за вграждане. `published` решава дали сградата се вижда публично |
| `layouts` | Типовите разпределения: полигоните на апартаментите в плана |
| `floors` | Етажите: контур върху рендера (`facade_polygon`) и кое разпределение ползват |
| `apartments` | Апартаментите: площи, стаи, изложение, цена, статус, PDF, връзка към HubSpot сделка |
| `status_history` | Всяка смяна на статус: от какво в какво, кога, кой и откъде (`admin`, `import`, `hubspot`, `api`, `seed`) |
| `leads` | Запитванията от widget-а и резултатът от изпращането им |
| `events` | Събития за статистиката: прегледи, отворени етажи и апартаменти, запитвания |

## Права (RLS)

- Анонимен посетител вижда само публикувани сгради, техните етажи, разпределения и апартаменти.
- Запитванията, историята и събитията не се виждат публично. Пишат се само от сървърните функции със `service_role`.
- Всеки потребител вижда и редактира само сградите на своята организация. Изтриване на сграда може само `owner`.
- Помощните функции за правата са в схема `private`, която не е достъпна през API-то.

## Публичен API за widget-а

```
POST {SUPABASE_URL}/rest/v1/rpc/get_public_building   { "p_slug": "bor" }
POST {SUPABASE_URL}/rest/v1/rpc/list_public_buildings { "p_org_slug": "liniya-demo" }
```

Извикват се с публичния (anon/publishable) ключ. Цената на апартамент се връща само ако е видима и апартаментът не е продаден.

## На живо

Таблицата `apartments` е в Realtime публикацията, така че widget-ът може да слуша промените в статуса и да се обновява без презареждане.

## Хранилище

Bucket `media` е публичен за четене. Качването е позволено само в папка с id-то на организацията: `media/{org_id}/...`.
