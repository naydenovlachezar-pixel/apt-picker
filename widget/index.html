Интерактивен избор на апартамент

Widget за сайтове на строители. Вгражда се с един ред код и работи върху всеки сайт: WordPress, Webflow, Wix или сайт по поръчка.

Вграждане

<div data-apt-picker data-building="bor"></div>
<script src="/embed.js" async></script>

Атрибути

АтрибутОписание
data-buildingСграда, която се отваря първа (bor, horizont, gradini, terakota, terasi, spirala)
data-buildingsКои сгради да се показват като раздели, разделени със запетая
data-apartmentДиректно отваряне на апартамент, например 5A
data-themelight или dark
data-offset-topВисочина на фиксирано меню на сайта в пиксели, за да не закрива прозорците
data-demoПоказва CRM демо панела

Събития

document.addEventListener("apt-picker:inquiry", e => {
  // e.detail: { building, buildingName, apartmentId, apartmentLabel }
  gtag("event", "generate_lead", { item_id: e.detail.apartmentId });
});
